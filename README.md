# 啵啵水族箱 · 微信小游戏内测版

原生 Canvas 2D 微信小游戏工程，AppID：`wxedb87cfb241f9dae`。版本 0.4.0。

**这是可导入的源代码工程，尚未上传微信、提交审核或完成真机验证。** 不需要安装 Node 或执行构建即可导入微信开发者工具。浏览器预览仅用于检查玩法和视觉；正式入口是根目录 `game.js`。

## 导入微信开发者工具

1. 解压工程包，找到包含 `project.config.json`、`game.js`、`game.json` 的 `bobo-aquarium` 文件夹。
2. 使用有该小游戏开发权限的微信账号登录微信开发者工具。
3. 导入这个文件夹，确认项目类型为**小游戏**、AppID 为 `wxedb87cfb241f9dae`。不选择普通小程序模板，不覆盖当前目录。
4. 点击编译。入口应显示「啵啵水族箱」首页。此工程无 npm 运行时依赖，不需要“构建 npm”。
5. 使用工具的预览功能在手机微信中扫码，验证触摸、声音、刘海屏及微信右上角胶囊区域。
6. 真机验证通过后，在开发者工具上传版本；再到该小游戏后台按账号实际要求完成资料、隐私说明、相关资质及审核发布流程。

微信官方开发文档：https://developers.weixin.qq.com/minigame/dev/guide/
微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 背景音乐（v0.3）

新增项目内合成的原创配乐「海洋微光」：80 BPM、48 秒循环、轻钟琴与柔和铺底。第一次点击后开始播放，音乐与音效可独立开关，偏好随存档保存。切后台、广告播放和系统音频中断时暂停，恢复时遵循开关状态。音频随工程打包，不依赖在线音乐服务。微信真机音频仍需验证。

- 广告位未配置时入口不可用，不假装播放广告，也不发放模拟奖励。
- 本地关卡、棋盘、步数、体力、贝壳、装饰和偏好存档；返回首页保留进行中的关卡。
- 首次通关 20 贝壳，重复通关 5 贝壳；6 个可购买的水族箱装饰。
- 免费走法提示、玩法说明、音效和震动开关。

## 接入真实激励广告

在 `src/config.js` 填入该小游戏后台创建并可用的广告位 ID：

```js
rewardedAdUnitId: "adunit-你的真实广告位ID";
```

AppID 与广告位 ID 是不同配置。仅有 AppID 不能播放激励广告。

广告适配层位于 `src/platform.js`，使用 `wx.createRewardedVideoAd`。只在 `onClose` 返回 `isEnded === true` 时申请发奖；取消、错误或没有完整观看均不奖励、不占用成功奖励次数。真实可用性、收益及广告资格以微信后台为准。

真机至少检查：完整观看、提前关闭、无填充/断网、重复点击、当日第 5/6 次、广告前后切后台、跨日恢复。工程内的广告测试使用 mock，不代表真实广告已验收。

官方广告接口：https://developers.weixin.qq.com/minigame/dev/api/ad/wx.createRewardedVideoAd.html

## 本地预览与测试（可选）

在此目录使用 Python 3：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8765/preview/`。该预览与微信入口共用 `src/` 中的业务和渲染代码。

安装有 Node.js 18+ 时运行：

```sh
node --test tests/*.test.js
```

没有外部运行时依赖。`tests/`、`preview/` 及说明文件通过 `packOptions` 排除在微信上传包之外。

## 当前边界

这是单机内测版本，尚未接入账号登录、云存档、服务端可信时间、服务端广告额度、运营数据统计或排行榜。本地存档可被清除，设备时间也可能被修改；因此当前“每天 5 次”是客户端体验规则，**不是防作弊的服务端保证**。正式商业运营前，应将每日额度和奖励账本迁到服务端，并对广告完成事件采用平台支持的校验方式。

当前不主动收集昵称、头像、手机号或定位。启用微信广告等能力后，仍需按后台真实能力配置隐私说明；文案不能代替实际审核要求。

30 关已做自动化走法检查和有限策略试玩，没有经过大规模真人留存测试，不应据此承诺留存率、收入或所有随机补充棋盘都可通关。
